# Task 2 — Customer Segmentation

Customer segmentation project completed for the Intern Alpha Data Analytics Internship.

## Objective

Identify distinct customer groups based on purchasing behavior using K-Means clustering.

## Features Used

- Total Revenue
- Total Quantity Purchased
- Number of Orders

## Analysis Covered

- Data Loading and Inspection
- Data Cleaning
- Customer-Level Aggregation
- Feature Scaling using StandardScaler
- K-Means Clustering
- Elbow Method
- Silhouette Score Evaluation
- Customer Segment Visualization
- Segment-Wise Business Analysis

## Customer Segments

- **Cluster 0 — Low-Value Customers**
- **Cluster 3 — Regular Customers**
- **Cluster 2 — High-Value Customers**
- **Cluster 1 — VIP Customers**

## Business Recommendations

- Use personalized promotions for low-value customers.
- Provide loyalty benefits to regular customers.
- Offer exclusive services to high-value customers.
- Maintain strong relationships with VIP customers.
- Use customer segmentation for targeted marketing strategies.
