# Task 1 — Sales Data Analysis

Sales data analysis project completed for the Intern Alpha Data Analytics Internship.

## Objective

Analyze sales data to identify sales trends, seasonal patterns, product performance, hourly sales activity, and city-wise performance.

## Analysis Covered

- Data Cleaning
- Overall Sales Performance
- Product Performance
- Top 10 Products by Units Sold
- Top 10 Products by Revenue
- Monthly Sales Trends
- Hourly Sales Patterns
- City-wise Sales Performance
- Average Order Value

## Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset

The dataset used for this internship task is not included in this repository.

The complete analysis, visualizations, and results are available in the Jupyter Notebook.

- `sales_analysis.ipynb` — Complete analysis and visualizations
